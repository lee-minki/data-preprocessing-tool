# data_cache/ — OPC 태그 로컬 캐시

자주 사용하는 OPC 태그 히스토리를 로컬 Excel에 저장해 두는 폴더입니다.
긴 시간 범위(예: 2020-01 이후 6년치)를 OPC에서 매번 읽지 않고 즉시 로드할
수 있도록 데스크톱 GUI(`📥 불러오기` 버튼)와 연동됩니다.

> 이 폴더 자체는 `.gitignore` 처리되어 있어 git에 올라가지 않습니다.
> 이 `README.md` 만 추적됩니다.

## 파일 구조

```
data_cache/
├── _index.xlsx          # 카탈로그 (자동 생성/갱신)
├── TI-101.xlsx          # 태그 1개 = 파일 1개
├── FI-205.xlsx
└── ...
```

각 태그 파일은 **연도별 시트**로 분리됩니다.

```
TI-101.xlsx
├── 2020   (~263,000행)
├── 2021   (~263,000행)
├── 2022
├── ...
```

2분 간격 기준 1년 ≈ 263,000행이라 단일 시트(최대 1,048,576행) 한계의
1/4 수준이고, 사용자가 Excel에서 직접 열어보기에도 부담이 없습니다.

## 컬럼 규약

각 시트는 다음 3개 컬럼만 사용합니다.

| 컬럼 | 의미 | 비고 |
|---|---|---|
| A: `datetime` | 시각 | `YYYY-MM-DD HH:MM:SS` 또는 Excel 인식 가능한 모든 형식 |
| B: `value` | 측정값 | 숫자 |
| C: `quality` | 품질 | 비어있으면 `Good` 으로 간주, 선택 사항 |

추가 컬럼·수식·병합 셀·숨김 행은 사용하지 마세요. 시스템이 무시하거나
오류를 낼 수 있습니다.

## 사용 흐름

### 1) 자동 캐시 (기본 동작)

OPC 탭의 **`📦 캐시 우선 사용`** 이 켜져 있으면:

1. 태그 + 시작/종료 시각을 입력하고 `📥 불러오기`
2. 시스템이 `data_cache/<tag>.xlsx` 를 먼저 확인
3. 요청 기간이 캐시 범위에 **완전히 포함**되면 → 즉시 로드 (OPC 호출 생략)
4. 캐시에 없거나 부분만 있으면 → 기존 OPC 흐름

**`자동 저장`** 이 켜져 있으면 OPC에서 새로 받아온 데이터는 끝나는 즉시
캐시 파일에 병합됩니다.

### 2) 수동 편집

언제든 Excel에서 직접 파일을 열어 편집할 수 있습니다.

- 행 추가: 시각 + 값 입력 (정렬 불필요, 시스템이 자동 정렬)
- 행 수정: 같은 시각이 여러 번 있으면 마지막 행이 우선
- 시트 추가: 연도별로 새 시트 추가 가능 (시트명을 `2027` 처럼 4자리 연도)
- 파일 추가: 새 태그 파일을 직접 만들어 넣어도 자동 인식

편집 후 `_index.xlsx` 는 다음 GUI 실행 시 자동으로 다시 만들어집니다.
직접 갱신하고 싶다면 `_index.xlsx` 를 삭제하면 됩니다.

### 3) Excel 외부에서 데이터 붙여넣기

다른 시스템 (DCS export, 사내 포털 다운로드 등) 에서 받은 Excel/CSV
데이터를 캐시로 가져오려면:

1. 데이터를 정리: `datetime`, `value`, `quality(선택)` 3개 컬럼만 남김
2. 시각 컬럼을 해당 연도 시트의 A열에 붙여넣기
3. 값 컬럼을 B열에 붙여넣기
4. 파일 저장

같은 시각의 기존 행이 있어도 시스템이 다음 로드 시 자동으로 병합·중복
제거합니다.

## 트러블슈팅

- **"캐시 부분 적중" 메시지**: 요청 기간 일부만 캐시에 있는 경우입니다.
  현재 MVP는 부분 적중을 자동 병합하지 않고 OPC로 재조회합니다. OPC
  자동 저장이 켜져 있으면 다음번에는 캐시 적중이 됩니다.
- **컬럼이 인식되지 않음**: A/B/C 컬럼명이 `datetime`, `value`,
  `quality` 인지 확인. 대소문자/공백은 자동 정리됩니다.
- **파일이 잠겨 있음**: Excel에서 해당 파일을 열어둔 상태에서 자동 저장이
  실행되면 실패합니다. 파일을 닫고 다시 시도하거나, 수동 저장 버튼을
  사용하세요.

2. 처음 시작하기

지원 환경

  • Windows: 실행 파일 또는 python gui_app.py
  • macOS: python gui_app_mac.py
  • 지원 형식: .xlsx, .xls, .csv

시작 전 알아둘 점

  • 날짜 컬럼은 Date, Time, Datetime, 날짜, 시간, timestamp 같은 이름으로 자동 감지합니다.
  • 필터와 이상값 처리 대상은 숫자형 컬럼만 표시됩니다.
  • Unnamed로 시작하는 빈 컬럼은 자동 제거됩니다.
  • 숫자 컬럼은 화면에 최대 30개까지 표시됩니다.
처음 사용자 추천

처음에는 sample_data.csv 같은 작은 파일로 전처리 한 번, 저장 한 번, Validation 한 번까지 직접 해보는 것이 가장 빠릅니다.

3. 화면 읽는 법

메인 화면 구성

  • 파일 선택: 데이터 파일을 여는 영역
  • 필터 조건: 여러 조건을 AND로 묶는 영역
  • 이상값 처리: 제거 기준을 정하는 영역
  • 정규화: 필요할 때만 켜는 선택 기능
  • 시간 처리: 시간 정규화/재정렬 옵션
  • 진행 상황: 진행률, 상태 문구, 예상 시간
  • 처리 결과: 처리 로그를 읽는 영역

바로 보이는 핵심 버튼

  • 파일 불러오기
  • + 필터 추가
  • 🚀 전처리 실행
  • 🧪 Validation 데이터 생성
  • 💾 결과 저장
  • ⏹ 취소

4. 처음 사용자용 기본 전처리 순서

  1. 프로그램을 실행합니다.
    Windows는 실행 파일 또는 python gui_app.py, macOS는 python gui_app_mac.py를 사용합니다.
  2. 파일 불러오기를 누릅니다.
    불러온 뒤 파일명, 행/열 수, 미리보기 테이블이 보이는지 먼저 확인합니다.
  3. 필터가 필요하면 추가합니다.
    예: AMBIENT_TEMP >= 15, FAN_CURRENT range 30 ~ 50
  4. 이상값 처리 방식을 선택합니다.
    일반적으로는 2.5σ부터 시작하는 것이 무난합니다.
  5. 필요한 경우에만 정규화와 시간 처리를 켭니다.
    수치 비교가 목적이면 정규화, 시간축이 어긋났다면 시간 정규화/재정렬을 사용합니다.
  6. 🚀 전처리 실행을 누릅니다.
    처리 결과 로그에서 필터 적용, 이상값 제거, 정규화, 시간 처리 결과를 순서대로 확인합니다.
  7. Validation 데이터가 필요하면 다음 단계로 생성합니다.
    전처리 중 제거된 행이 있을 때만 생성 가능합니다.
  8. 💾 결과 저장으로 마무리합니다.
    전처리 결과만 저장할지, Validation 파일도 같이 만들었는지 목적에 맞게 확인합니다.
중요 Validation 데이터 생성은 전처리를 먼저 실행한 뒤에만 의미가 있습니다. 제거된 행이 없으면 생성되지 않습니다.

5. 기능별 상세 사용법

5-1. 파일 불러오기

  1. 파일 불러오기 또는 메뉴 파일 > 열기...를 누릅니다.
  2. Excel/CSV 파일을 선택합니다.
  3. 상단 파일명과 데이터 정보가 바뀌는지 확인합니다.
  4. 미리보기 테이블에서 날짜 컬럼과 숫자 컬럼이 예상대로 들어왔는지 확인합니다.

CSV는 UTF-8 → CP949 → EUC-KR 순으로 자동 읽기를 시도합니다.

5-2. 필터 조건

필터는 모두 AND로 결합됩니다. 즉, 여러 조건을 넣으면 모두 만족하는 행만 남습니다.

연산자>=, <=, >, <, =, !=, range
예시AMBIENT_TEMP >= 15
FAN_CURRENT range 30 ~ 50
주의range는 최소 또는 최대 한쪽만 입력해도 동작하지만, 숫자형 컬럼에만 사용할 수 있습니다.

5-3. 이상값 처리

방법2σ, 2.5σ, 3σ, IQR
추천 시작점2.5σ
실제 동작이상값이 포함된 행은 항상 전체 삭제됩니다.
후속 영향제거된 행은 Validation 데이터 생성과 시뮬레이션 데이터 생성의 재료로 사용됩니다.

5-4. 정규화

  • Z-Score: 평균 0, 표준편차 1 기준으로 변환합니다.
  • Min-Max: 값을 0~1 범위로 맞춥니다.

컬럼 간 스케일 차이가 크면 정규화를 켜고, 원본 단위 유지가 중요하면 끄는 편이 좋습니다.

5-5. 시간 처리

시간 정규화어긋난 시간을 가장 가까운 간격으로 보정합니다. 체크박스 문구는 2분 기준으로 보이지만 실제 계산은 간격(분) 입력값을 사용합니다.
시간 재정렬지정한 시작 시각부터 같은 간격으로 시간축을 새로 만듭니다.
추천 상황엑셀 자동채우기 때문에 초 단위가 밀렸거나, 필터링 후 시간축을 다시 만들고 싶을 때

5-6. 결과 저장

  1. 💾 결과 저장 클릭
  2. 저장 형식(CSV/Excel)과 경로 선택
  3. 저장된 파일 확인
  • 기본 파일명은 원본이름_processed_YYYYMMDD_HHMMSS 형식입니다.
  • 날짜 컬럼은 YYYY-MM-DD HH:MM:SS 형식으로 저장됩니다.
  • CSV는 utf-8-sig로 저장됩니다.

6. 프리셋 기능

반복 작업이 많으면 프리셋을 먼저 익히는 것이 가장 효율적입니다.

저장 / 불러오기 / 관리

  • 프리셋 저장...: 현재 설정을 이름으로 저장
  • 프리셋 불러오기...: 저장한 설정을 다시 적용
  • 프리셋 관리...: 목록 확인, 삭제, 새로고침

내보내기 / 가져오기

  • 프리셋 내보내기...: 프리셋을 JSON 파일로 저장
  • 프리셋 가져오기...: 받은 JSON 프리셋을 등록
  • 기본 저장 위치: ~/.data_preprocessor/presets/

파일 + 프리셋 한번에 열기

  1. 프리셋 > 파일+프리셋 한번에 열기... 선택
  2. 적용할 프리셋 선택
  3. 데이터 파일 선택
  4. 필요하면 불러온 후 자동으로 전처리 실행 또는 전처리 후 자동 저장 옵션 사용

7. 분석 및 생성 기능

7-1. 트렌드 차트

  • 메뉴: 분석 > 📊 트렌드 차트...
  • 최대 5개 컬럼까지 비교 가능
  • Ctrl+클릭으로 다중 선택
  • 자동 스케일, 평균선, 0~1 정규화 비교, 최소/최대/평균/표준편차 확인 가능

전처리를 먼저 실행해서 processed_df가 있어야 사용할 수 있습니다.

7-2. Validation 데이터 생성

  1. 전처리를 먼저 실행합니다.
  2. 🧪 Validation 데이터 생성 버튼을 누릅니다.
  3. 이상값 발생 컬럼을 1개 이상 선택합니다.
  4. Validation 비율과 내부 구간 비율 4개를 입력합니다.
  5. Sigma 시작/끝 배수를 입력합니다.
  6. 💾 3개 파일 자동 생성을 누릅니다.
생성 조건전처리 중 제거된 행이 있어야 함
자동 생성 파일원본이름_prepro.xlsx
원본이름_prepro_with_valid.xlsx
원본이름_valid.xlsx
주의내부 비율 4개 합계는 100이어야 하며, 이상값 발생 컬럼을 최소 1개 선택해야 합니다.

7-3. 시뮬레이션 데이터 생성

이 기능은 제거된 이상값을 활용해 정상 → 점진 전환 → 비정상 흐름의 테스트용 데이터를 만듭니다.

  • 대상 컬럼을 1개 이상 선택해야 합니다.
  • 전처리와 이상값 제거가 먼저 수행되어야 합니다.
  • 출력 기본 파일명은 Simulation_Data_YYYYMMDD_HHMMSS.xlsx 입니다.
  • 출력 시트명은 Simulation 입니다.

7-4. 도움말 / 용어 설명 / 프로그램 정보

  • 사용자 매뉴얼: 이 HTML 문서를 브라우저로 엽니다.
  • 용어 설명: 이상값 처리와 정규화 개념을 간단히 확인합니다.
  • 프로그램 정보: 버전, 주요 기능, 개발자 정보 확인
  • 패치노트 보기: 변경 이력 확인

9. 자주 막히는 상황과 해결 방법

파일이 열리지 않을 때

  • 확장자가 .xlsx, .xls, .csv인지 확인
  • CSV 인코딩이 깨지면 UTF-8/CP949/EUC-KR 여부 확인
  • 파일이 다른 프로그램에서 열려 있지 않은지 확인

필터 컬럼이 안 보일 때

  • 숫자형 컬럼인지 확인
  • 문자 컬럼, 날짜 컬럼은 필터 목록에 직접 나오지 않음

날짜 컬럼이 인식되지 않을 때

  • 컬럼명에 Date, Time, Datetime, 날짜, 시간, timestamp 중 하나가 포함되는지 확인
  • 날짜 형식이 너무 불규칙하면 원본 파일을 먼저 정리

Validation 데이터 생성이 안 될 때

  • 전처리를 먼저 실행했는지 확인
  • 실제로 제거된 행이 있는지 확인
  • 선택한 태그가 숫자형 컬럼인지 확인
  • 내부 구간 비율 합계가 100인지 확인
대용량 데이터 안내 행 수가 많으면 처리 시간이 길어질 수 있습니다. 이 경우 진행률 바와 상태 문구를 먼저 확인하고, 중간에 파일을 다시 여는 대신 처리가 끝날 때까지 기다리는 편이 안전합니다.

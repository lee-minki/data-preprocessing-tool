업로드부터 결과 확인까지

이 매뉴얼은 현재 웹 화면 기준입니다. 핵심은 프리비전 모델링 준비 과정에서 왜 이 단계가 필요한지 이해한 뒤, 업로드 직후 바로 실행하지 말고 먼저 원본 추세와 시간축을 확인하는 것입니다.

먼저 할 일업로드 후 파일 정보, 원본 추세, 시간축 상태 확인
성공 기준전처리 1회 실행 후 저장 결과와 로그 확인

1. 5분 빠른 시작

처음에는 모든 옵션을 익히기보다 아래 순서대로 한 번 성공하는 것이 가장 빠릅니다. 메인 화면의 인터랙티브 매뉴얼 시작 또는 좌측 사용 순서를 누르면 각 단계가 왜 필요한지와 기존 절차 대비 무엇이 자동화되었는지부터 실행·자동 저장·로그 재확인까지 실제 화면 위에서 바로 확인할 수 있습니다.

  1. 1
    메인에서 파일 업로드

    XLSX 파일을 드래그하거나 파일 선택으로 불러옵니다.

  2. 2
    파일 정보와 원본 추세 확인

    파일명, 행/열 수가 맞는지 확인하고 우측 차트에서 전체 흐름과 튀는 구간, 시간축 상태를 먼저 읽습니다.

  3. 3
    기본값으로 1회 실행

    필요하면 OPC helper 태그로 Operation Condition 판단 기준을 보완한 뒤, 이상값 처리 2.5σ, 선제거 1회 선제거 · MAD 기반, Validation 20% 고정값으로 먼저 시작하면 됩니다.

  4. 4
    전처리 실행 · 자동 저장

    진행률이 끝날 때까지 기다리고, 실행 버튼 아래의 저장 파일 구성과 로그 완료 메시지를 확인합니다.

  5. 5
    저장 결과와 차트 확인

    전처리데이터(정상 Validation 20% 포함)와 Simulation Data 생성 여부, 통계 비교와 로그를 확인하면 첫 실행은 성공입니다.

처음 사용할 때 가장 안전한 방법

처음부터 필터를 많이 넣기보다 기본값으로 한 번 실행해 보고, 그다음 필요한 기준만 하나씩 조정하세요.

화면에서 바로 배우는 방법

메인 화면 좌측의 사용 순서 항목이나 인터랙티브 매뉴얼 시작 버튼을 누르면 해당 부위로 자동 이동하고, 하이라이트와 설명 카드로 왜 이 단계가 필요한지, 기존 절차 대비 무엇이 자동화되었는지, 실행 후 어떤 파일과 로그를 확인해야 하는지 단계별로 안내합니다.

2. 화면 구조

이 도구는 좌측에서 규칙을 정하고 우측에서 결과를 확인하는 구조입니다. 어디를 먼저 보면 되는지만 알면 훨씬 빠르게 적응할 수 있습니다.

좌측 상단

파일 정보

파일명, 행 수, 열 수를 보고 현재 불러온 데이터가 맞는지 가장 먼저 확인합니다.

좌측 중단

기준 설정

이상값 처리, 선제거, 필터, 시간 처리, Validation / Simulation 조건을 같은 순서로 정합니다. 각 i 도움말과 인터랙티브 매뉴얼로 왜 이 기준이 필요한지와 기존 절차 대비 무엇이 자동화되었는지 함께 확인할 수 있습니다.

우측 상단

데이터 분석

원본/전처리 후 추세, 분포, Validation 경계를 확인하는 핵심 검토 영역입니다.

우측 하단

테이블과 로그

실제 값 미리보기와 처리 결과 메시지를 보고 실행이 제대로 끝났는지 확인합니다.

3. 실제 작업 흐름

실무에서는 아래 네 단계만 기억하면 됩니다. 핵심은 설정 전에 먼저 원본을 보고, 필요하면 Operation Condition 판단 기준을 보완한 뒤, 전처리와 검증 준비를 같은 흐름으로 연결하는 것입니다.

Step 1

기본 상태 확인

파일명, 행/열 수, 날짜 컬럼 인식 상태, 숫자 컬럼 목록이 예상과 맞는지 확인합니다.

Step 2

원본 추세 확인

차트에서 튀는 구간, 급격한 변화, 분포 왜곡이 있는지 먼저 보고 이상값 처리 강도를 정합니다.

Step 3

필요한 기준 설정

필요하면 OPC helper 태그로 Operation Condition 판단 기준을 보완하고, 필터는 최소한으로 넣습니다. 시간 처리는 프리비전 업로드 적합성이 필요한 경우에만 켭니다.

Step 4

로그와 저장 결과 확인

제거된 행 수, 최종 데이터 수, 자동 저장 파일 구성, Simulation 저장 여부를 순서대로 검토합니다.

4. 시간 처리

가장 자주 헷갈리는 부분입니다. 두 기능은 비슷해 보여도 목적이 다르며, 특히 프리비전 업로드용 2분 단위 시간축 적합성을 맞출 때 중요합니다.

시간 정규화

가까운 간격으로 보정

예: 00:01:00 → 00:02:00, 00:02:01 → 00:02:00. 원래 시간의 흐름은 유지하면서 엑셀 자동채우기 오차 같은 작은 틀어짐을 고칩니다.

시간 재정렬

새 시간축 다시 부여

필터 후 남은 데이터에 일정 간격의 새 시간표를 붙이는 기능입니다. 원래 수집 시각이 중요하면 신중히 사용해야 합니다.

쉽게 구분하는 법

시간 정규화는 “틀어진 시간을 바로잡는 것”, 시간 재정렬은 “시간표 자체를 새로 만드는 것”입니다. 웹 UI에서는 시작 시간이 홀수 분이면 직전 2분 배수로 자동 보정됩니다. 예: 10:05:00 → 10:04:00.

5. 저장 결과와 차트

전처리 실행이 끝나면 자동 저장 파일 구성과 차트 검토까지 확인해야 작업이 완결됩니다.

원본이름_prepro_with_valid.xlsx 전처리 완료 데이터와 뒤쪽 20% 정상 Validation 구간이 함께 들어가는 기본 자동 저장 결과 파일입니다.
Simulation_Data_YYYYMMDD_HHMMSS.xlsx 정상 → 전환 → 이상 구간으로 만든 Alert 점검용 시뮬레이션 파일입니다. Simulation 대상 컬럼과 구간 비율 설정에 따라 생성됩니다.
원본이름_prepro.xlsx / 원본이름_valid.xlsx 필요 시 수동 분리 저장에서 쓰는 전처리 본문과 Validation 전용 구성입니다. 기본 자동 저장 흐름은 _prepro_with_valid.xlsx를 중심으로 확인합니다.
차트에서 꼭 봐야 하는 것

원본 비교 버튼으로 전처리 전/후 차이를 보고, 📊 Val 보기로 정상 Validation 경계가 예상과 맞는지 확인하세요.

6. 자주 막히는 상황

대부분은 설정 오류보다 확인 순서를 놓쳐서 생깁니다. 아래 항목부터 보면 빠르게 해결됩니다.

파일이 안 열릴 때

.xlsx 형식인지 확인하고, 보안 문서라면 해제 후 다시 시도하세요.

필터 컬럼이 안 보일 때

필터는 숫자형 컬럼 중심으로 표시됩니다. 문자 컬럼과 날짜 컬럼은 직접 필터 대상으로 쓰기 어렵습니다. 필터는 조건에 맞는 행만 남기며, 특정 값을 제외하려면 != 조건을 사용합니다.

Simulation이 생성되지 않을 때

전처리 과정에서 실제로 제거된 이상값이 있어야 합니다. 대상 태그 선택과 비율 합계 100도 함께 확인하세요.

시간 결과가 예상과 다를 때

정규화와 재정렬을 혼동한 경우가 많습니다. 어떤 기능을 켰는지와 간격(분) 값을 먼저 확인하세요.

가장 많이 하는 실수

원본 추세를 보기 전에 바로 실행하는 것입니다. 먼저 전체 흐름과 분포를 보고 기준을 정해야 과도한 제거를 피할 수 있습니다.

7. 최종 점검표

아래 항목이 모두 맞으면 기본 전처리 작업은 정상적으로 마무리된 것입니다.

  • 1
    파일 정보가 맞다

    파일명, 행/열 수, 기본 인식 상태를 확인했다.

  • 2
    원본 추세를 먼저 봤다

    설정 전에 차트와 분포를 확인했다.

  • 3
    필요한 기준만 넣었다

    필터, 이상값 처리, 시간 처리를 과도하게 사용하지 않았다. 웹 UI에서는 이상값 대상 컬럼을 1개 이상 직접 선택해야 한다.

  • 4
    전처리 완료 로그를 확인했다

    제거된 행 수, 최종 데이터 수, 완료 메시지를 확인했다.

  • 5
    Validation / Simulation 결과를 확인했다

    Validation 자동 구성과 Simulation 저장 여부를 로그와 화면에서 확인했다.

  • 6
    자동 저장 파일 구성을 확인했다

    _prepro_with_valid.xlsx와 Simulation 파일이 기대대로 생성됐는지 실행 영역과 로그에서 확인했다.

여기까지 끝났다면

기본 전처리 작업은 혼자 처리할 수 있는 수준입니다. 반복 작업이 많아질 때 프리셋 저장/불러오기를 쓰면 됩니다.

v1.7.0

σ 조기경보 시계열 데이터 전처리프로그램

이 문서는 Windows용 전처리 앱의 화면 구성, 동작 순서, Validation 데이터 생성 방식, 저장 파일 규칙을 한 번에 이해하기 위한 HTML 사용자 매뉴얼입니다.

빠른 이해

프로그램이 하는 일

1. 원본 데이터 불러오기 Excel(.xlsx, .xls) 또는 CSV 파일을 열고 날짜/숫자 컬럼을 자동 감지합니다.
2. 전처리 필터링, 이상값 제거, 정규화, 시간 보정, 시간 재정렬을 순서대로 적용합니다.
3. Validation 데이터 생성 제거된 이상 행과 표준편차 기반 synthetic 데이터를 섞어 검증용 파일을 자동 생성합니다.

기본 사용 순서

파일 불러오기 파일 불러오기 버튼으로 데이터를 엽니다. 숫자 컬럼과 날짜 컬럼이 자동 감지됩니다.
필터 조건 설정 필요하면 + 필터 추가로 범위 조건 또는 비교 조건을 넣습니다.
이상값/정규화/시간 처리 선택 목적에 따라 옵션을 켭니다. 일반적으로 이상값 제거는 켠 상태로 사용합니다.
전처리 실행 🚀 전처리 실행을 누르면 필터링 → 이상값 제거 → 정규화 → 시간 보정/재정렬 순으로 수행됩니다.
결과 저장 또는 Validation 생성 전처리 결과를 저장하거나, 분석 > Validation 데이터 생성으로 검증용 파일 3종을 생성합니다.

💾 3개 파일 자동 생성 닫기
결과 영역: 생성 성공/실패 메시지와 저장 경로가 표시됩니다.
대상 컬럼 선택 이상 패턴을 넣을 태그를 다중 선택합니다. 선택하지 않은 컬럼은 최근 정상 추세를 최대한 유지합니다.
Validation 비율 전처리 결과 행 수 대비 validation 블록 길이 비율입니다. 기본값은 20%입니다.
내부 구간 비율 4개 기본값은 25 / 25 / 25 / 25입니다. 순서는 정상1 → 제거행 기반 이상 → 정상2 → Sigma 기반 이상입니다.
Sigma 시작/끝 마지막 Sigma 구간에서 평균 대비 몇 표준편차까지 벗어날지 지정합니다. 기본값은 2.5σ ~ 4.0σ입니다.
자동 저장 파일 미리보기 생성 버튼을 누르면 원본 파일 폴더에 저장될 3개 파일 경로를 미리 보여줍니다.
1 대상 컬럼 여기서 고른 태그만 이상 패턴이 바뀝니다. 선택하지 않은 태그는 정상 추세를 최대한 유지합니다.
2 Validation 비율 전처리 결과 길이 대비 몇 %를 validation 블록으로 만들지 정합니다. 기본값은 20%입니다.
3 구간 비율 4개 정상1, 제거행 기반 이상, 정상2, sigma 기반 이상 순서입니다. 합계는 반드시 100이어야 합니다.
4 Sigma 시작/끝 마지막 구간에서 평균 대비 얼마나 벗어날지를 정합니다. 값이 클수록 더 강한 이상 패턴이 만들어집니다.
5 자동 생성 버튼 눌렀을 때 전처리본, 전처리+validation, validation 전용 파일 3개를 원본 폴더에 저장합니다.

예시 시나리오

실무에서 자주 쓰는 흐름

  1. sample_data.csv 또는 실데이터를 불러옵니다.
  2. AMBIENT_TEMP >= 15, FAN_CURRENT 30~60 같은 필터를 넣습니다.
  3. 이상값 처리 방법을 2.5σ로 선택합니다.
  4. 필요하면 시간 재정렬을 켜고 시작 시간과 간격을 입력합니다.
  5. 🚀 전처리 실행으로 데이터 품질을 맞춥니다.
  6. 분석 > Validation 데이터 생성을 열어 대상 태그와 비율을 선택합니다.
  7. 생성된 *_prepro_with_valid.xlsx 또는 *_valid.xlsx를 시뮬레이션/검증에 사용합니다.
문제 해결

자주 발생하는 문제

  • 파일 로드가 안 되면 문서보안(AIP/DRM) 해제가 필요한지 먼저 확인합니다.
  • Validation 생성 버튼이 안 되면 먼저 전처리를 실행하고, 실제 제거된 행이 있는지 확인합니다.
  • Sigma 입력값을 직접 수정했다면 숫자인지 확인합니다.
  • 저장 파일이 덮어써질 수 있으므로 같은 이름 파일이 남아있는지 확인합니다.

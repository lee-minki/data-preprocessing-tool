DATA PREPROCESSING CONTROL ROOM

업로드 뒤 바로 이어지는 전처리 흐름

현업 파일을 올리면 원본 추세 확인, 기준 설정, 자동 저장까지 기존 전처리 화면에서 바로 이어집니다.

무엇을 하나 모델링 전 데이터 정리와 산출물 생성을 한 흐름으로 묶습니다.
누가 쓰나 실사용자, 검토자, 운영 담당자가 같은 기준으로 봅니다.
추가 안내 소개와 매뉴얼은 필요할 때만 참고하면 되고 시작은 업로드 카드면 충분합니다.

📊 이상값 처리 i ▼
방법
처리: 이상값 포함 행 전체 삭제
필터링 강도 가이드
2σ: 더 많이 제거 → 학습 데이터는 더 촘촘/보수적, 전체 양은 감소
2.5σ: 균형형 (기본)
3σ: 덜 제거 → 데이터 양은 더 많이 유지, 이상값 일부 잔존 가능
방법 선택 요약
MAD: 아주 큰 극단값을 먼저 잘라내는 1차 정리
IQR: 비대칭 분포에서 안정적인 제거 기준
3σ: 데이터를 많이 남기고 극단값만 제거하는 보존형 기준
선제거 모드 i
언제 쓰나
극단값이 평균/표준편차를 먼저 오염시키는 경우, 메인 이상값 처리 전에 선제거를 적용하면 트렌드를 더 안정적으로 확인할 수 있습니다.
선제거 해석
MAD 선제거: 아주 튀는 값 먼저 제거
반복 clipping: 선제거를 여러 번 반복해 평균/표준편차 왜곡을 줄임
